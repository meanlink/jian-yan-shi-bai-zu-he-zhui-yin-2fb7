# 三室联合共败分析（隐私保护 MPC 演示）

三家检验室联合挖掘“三室同败”规则，**各室批号与逐批标签不出本室**；协调端
只能得到三室合计计数，任何接口都读不到单室计数。纯 Python 标准库实现，无
第三方依赖。

## 1. 威胁模型与隐私边界

| 数据 | 存放位置 | 协调端可见？ |
| --- | --- | --- |
| 批号 `batch_id`、逐批判败标签 | 仅参与端本地 SQLite | 否，永不进入任何对外消息 |
| 样本公开属性（试剂批、仪器、温区） | 冻结清单 | 是（不含批号/标签） |
| 跨室协议消息 | 密封信封（Encrypt-then-MAC） | 否，只能转发密文 |
| 共败/全通过计数 | 加法秘密分享 | 仅三家求和后的合计 |
| 池化判败次数 | 成对掩码向量 | 仅三家求和、掩码抵消后的合计 |

- 单份秘密分享在域 `p=2^61-1` 上均匀随机，协调端持有单份等价于随机数。
- 成对掩码 `m_ij` 由两端共享密钥确定性生成，三家求和时整体抵消。
- 协调端不提供任何“按室拆分”的接口，从机制上杜绝两轮差分反推单室。

## 2. 协议流程（每轮先冻结，少一家永不推进）

轮次创建即**冻结成员（三室）、样本清单、挖掘阈值**，之后不可更改。状态机：

```
frozen → triple → input → mult → aggregate → completed
（任一步任一室退出 → void，整轮作废，晚包不复活）
```

1. **frozen/join**：三室各发本轮临时 DH 公钥，并用 Schnorr 证明对
   “轮次 ID + 清单指纹”做承诺（跨轮改包无法通过验证）。
2. **triple**：分布式生成三输入 AND 相关随机量
   `(a,b,c,ab,ac,bc,abc)` 的三份加法分享，门 `g` 固定由 `g%3` 号室生成。
3. **input**：各室把 0/1 标签切三份分享密封发出，批号本身不出室。
4. **mult**：开放差 `d_i=x_i-a_i` 等密封交换（单看 `d_i` 不泄露 `x_i`），
   一次通信完成两个三输入 AND：`xyz`（三室同败）与
   `(1-x)(1-y)(1-z)`（三室全通过）。
5. **aggregate**：按规则单元汇总份额；池化败数加成对掩码后上报。
6. 协调端三家求和还原**合计**，在合计上挖掘规则并生成可追溯简报。

## 3. 规则口径（全通过样本仍计入分母）

- 分母 `D`：单元内全部样本数，**全通过样本照常计入**。
- 共败数 `C`：同一批号三室均判败（标签 AND，MPC 计算）。
- 池化败数 `F`：三室判败次数之和；池化败率 `= F/(3D)`。
- 共败率 `= C/D`，并给出相对总体基线的 lift。
- 阈值：`min_support`、`min_common_rate`、`min_pooled_rate` 在冻结时固定。

## 4. 可靠性与并发语义

- **冻结**：成员/样本/阈值创建即锁定，后续提交不得改变口径。
- **全有或全无**：每步必须三家到齐才原子推进；少一家永远停在当前步，
  不产生任何部分结果。
- **重试不重复计数**：每步包在发送前落盘，内容哈希去重；重试重放原包，
  返回 `duplicate_ignored`。
- **同室异包 / 跨轮包拒收**：同一室同一步内容漂移即拒；跨轮包的 Schnorr
  承诺与信封 AAD 双重失效。
- **退出即作废**：任一室退出，整轮转 `void`，已收信封随轮次失效，迟到包
  不再受理（不复活）。
- **中断恢复**：参与端状态与已发包存 SQLite，进程重启后从原轮恢复、重放，
  不重新生成随机量、不重复计数。
- 所有状态转换在协调端单锁内原子完成，并发收齐/退出只会得到完整结果或作废。

## 5. 目录与运行

```
cofail/
├── common/        # 密码原语、协议常量、规则挖掘、SQLite 封装
├── coordinator/   # 协调端服务 + 发起/进度/简报页面
├── lab/           # 参与端服务 + 参与/退出/进度页面（三室各跑一份）
├── demo/          # 演示数据、一键启动、端到端与 HTTP 冒烟脚本
└── tests/         # 18 个单元测试（密码、MPC、状态机、隐私边界）
```

一键启动四个服务（自动模式）：

```bash
bash cofail/demo/start_all.sh
# 协调端 http://127.0.0.1:8100 ；参与端 8101/8102/8103
```

命令行演示（需先启动服务）：

```bash
python3 -m cofail.demo.cli_demo
```

不开服务的对象级全流程（含退出/拒收/恢复四个场景）：

```bash
python3 -m cofail.demo.run_demo
```

真实 HTTP 四进程冒烟（自动起停服务）：

```bash
python3 -m cofail.demo.http_smoke
```

单元测试：

```bash
python3 -m unittest discover -s cofail/tests -p "test_*.py"
```

## 6. 网页操作

- 协调端（8100）：输入调查员口令与清单/阈值发起轮次、查每步三家到齐进度、
  查看简报与追溯指纹。
- 参与端（8101/8102/8103）：填本室令牌、导入私有数据（仅落本室库）、
  一键加入/推进、退出整轮、查看本室提交进度。

## 7. 演示数据

`demo/make_data.py` 确定性生成 60 个样本，埋点三条共败信号（试剂批 R-7、
仪器 INSP-2、高温带 T-H），并保留足够的全通过样本以验证“全通过计入分母”。
脚本只在控制台打印聚合层面的事实核对，不导出单室明细。
